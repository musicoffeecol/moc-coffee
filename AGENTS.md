# Reglas del repositorio

- Mantener compatibilidad con GitHub Pages y `HashRouter`.
- No eliminar `base: '/moc-coffee/'` de `vite.config.ts`.
- No introducir backend ni integrar pagos reales.
- Mantener TypeScript estricto.
- Ejecutar `npm run lint` y `npm run build` antes de finalizar.
- Mantener los datos mock separados de los componentes.
- No presentar datos comerciales, productores o certificaciones inventadas como definitivos.
- Conservar la identidad visual MØC y su paleta oficial.
- Mantener accesibilidad por teclado, contraste y respeto por movimiento reducido.
- Evitar dependencias innecesarias.
